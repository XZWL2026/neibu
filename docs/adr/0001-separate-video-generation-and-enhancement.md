# 内部项目的视频生成交付与超分增强解耦

适用范围：codex/internal-deployment 内部项目。clean/core 保留原有的腾讯 MPS 自动增强后交付流程，不采用本决策。

现有方舟视频链路将较低分辨率的原生生成与自动超分绑定，用户必须等待增强完成才能取得最终视频。内部项目选择直接交付原生视频，超分增强改为用户在视频生成页面对选定视频主动发起的处理，以减少不需要增强时的等待和处理成本。

用户选择的生成分辨率直接用于请求供应商的原生输出；生成页面只提供模型实际支持的原生档位，不通过自动增强补足档位。本人新生成及历史生成的视频均可主动增强，首版不开放外部视频上传。

生成和增强分别计费，增强提交前展示费用；增强失败只退增强费用，不影响原生成任务的成功状态。原生版与增强版分别保留，供用户预览和下载，增强结果不覆盖原视频。

本项目使用新的空数据库，没有历史成品或在途任务，因此本次改造不需要旧任务兼容或数据迁移。其余增强和版本管理规则见 [0002](0002-enhancement-versions-and-charging.md)。
