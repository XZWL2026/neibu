# 增强任务独立计费，增强版本归属于原视频记录

适用范围：codex/internal-deployment 内部项目。clean/core 的增强属于生成交付链路，不向用户提供本决策中的可选增强入口或独立增强计费。

生成与增强解耦后，增强是一项独立付费处理，但它的成果仍归属于原视频记录。选择按原生视频关联增强版本，而不是覆盖原生版或创建独立的历史卡片，让用户在同一处比较、预览、下载各版本，并使增强失败不改变生成任务的成功状态。

## 已确认规则

- 首版仅增强本人成功生成的原生视频，包括今后形成的历史视频；不接受外部上传，不对增强版继续增强。
- 增强目标支持 720p、1080p、2K、4K（2026-10-19 新增 2K，即 1440p，16:9 为 2560×1440）。仅展示高于原生档位且有匹配模板和价格的可用目标；不提供同分辨率的画质增强。目标是否可用取决于源视频规格、画幅与后台实际配置，不因目标在列表中就默认支持所有输入。
- 同一原生视频可以拥有不同目标档位的增强版。相同原生视频、相同目标已有成功结果时直接使用；该目标处理中禁止重复提交。明确失败后可重新付费重试，原失败增强费用退款，原生成费用和原生视频不受影响。
- 增强价格独立由后台配置，以目标分辨率和视频秒数计价，沿用用户适用的账户价格规则。使用源视频实际时长，向上取整到整数秒，例如 5.03 秒按 6 秒计费。缺少增强价格时不允许提交；提交前展示本次费用。
- 在视频生成页与共用的历史视图中，每个原生视频旁提供“超分增强”入口，选择档位并确认费用。原生版和各增强版在原记录中切换，各增强任务独立显示处理状态；切页或重新进入页面仍能恢复查看进度。
- 用户隐藏原视频记录时，整组隐藏原生版与各增强版，沿用现有不删除实际文件的行为。记录存在处理中增强任务时，暂不允许隐藏。

## 实施边界与验收

新生成按所选原生档位直接请求供应商、归档并交付，不依赖 MPS 配置或增强成功。手动增强需要独立的任务状态、费用与退款，并关联所选原生输出；现有“重新生成”会隐藏旧记录，不能直接作为增强入口。

增强提交前核对原任务成功状态、文件归属与结果关联、源文件可读性、真实视频规格、模板和价格可用性。服务端限制输入来源与重复提交，页面禁用按钮不能代替这些检查。模板和价格由后台决定，用户只选择可用目标档位。

实现后必须验证：原生交付不调用 MPS；不支持的原生档位不可提交；跨用户或无效来源被拒绝且不扣费；重复提交不会重复创建付费处理；增强成功保留原生版且可分别下载；增强失败只退款自身；不同目标版本正确关联；费用按真实时长向上取整且缺价拒绝；切页后进度可恢复；处理中禁止隐藏，终态后整组隐藏。
